## 1. صيدلية النهدي (nahdionline.com)

### 1.1 طبيعة الموقع
- موقع **تجارة إلكترونية مخصص** مبني على **Next.js** (وليس على منصة سلة).
- لغة الواجهة: العربية (RTL) مع خيار English.
- مناطق الشحن: السعودية، الإمارات (وغيرها).

### 1.2 الصفحات/الأقسام المكتشفة
- الصفحة الرئيسية
- جميع الفئات (قائمة ضخمة: عطور، مكياج، عناية بالأطفال والحفاضات، فيتامينات، عناية بالبشرة، مستلزمات الأطفال، عناية شخصية، عناية بالشعر، حليب وطعام الأطفال، تغذية رياضية، أجهزة طبية، رعاية صحية منزلية، تغذية صحية، عناية نسائية، عناية بالجسم والاستحمام)
- عروض اليوم
- مجلة العروض
- مركز النهدي للعناية الصحية
- نهدي جلوبال
- Nuhdeek (برنامج ولاء)
- سلة التسوق (`/ar-sa/my-cart`)
- قائمة أمنيات
- حساب: معلومات الحساب، دفتر العناوين، بطاقات محفوظة، طلباتي، اطلب مجددًا
- صفحات informational: معلومات التوصيل، الاستبدال والاسترجاع، اتصل بنا، الأسئلة الشائعة، سياسة الخصوصية، الشروط والأحكام

### 1.3 الميزات (Features)
- شحن Express (توصيل سريع).
- تقييمات المنتجات (1.0–5.0).
- خصومات (وفر X%).
- كوبونات/عروض.
- دفع: Mada، Visa، Apple Pay ( implied by payment icons).
- بحث (Search box).
- اختيار طريقة الشحن + تحديد موقع.
- تطبيق موبايل (iOS/Android) + smart banner.
- Scan & Go.
- cookie consent (Securiti.ai).
- تتبع: Google Tag Manager (GTM-P7T3BTR3)، Criteo، CreativeCDN.

### 1.4 سلة التسوق
- URL: `/ar-sa/my-cart`
- حالياً فارغة ("ليس لديك أي عناصر في سلة التسوق الخاصة بك حتى الآن").
- تدفق: إضافة للسلة (add to cart) من صفحة PLP/PDP → سلة → دفع.

### 1.5 Tech Stack (من HTML)
- Next.js (chunks `/_next/static/...`).
- CSS modules (multiple css files).
- Contentful? (preconnect `images.ctfassets.net`) — likely CMS.
- DAM: `dam.nahdionline.com` (images).
- Bazaarvoice (reviews): `api.bazaarvoice.com`.
- Securiti (consent).

## 2. منصة سلة (salla.com / s.salla.sa)

### 2.1 نبذة
- منصة تجارة إلكترونية سعودية (SaaS) — "+68,000 متجر نشط"، "+65,000,000,000 ريال مبيعات"، "250 مليون طلب".
- تدعم 40+ لغة، 79+ دولة لاستقبال المدفوعات، شحن دولي/محلي.
- حاصلة على عضوية "تقنية سعودية" (صنع في السعودية).

### 2.2 التسجيل
- URL: `https://s.salla.sa/auth/register`
- حقول: الاسم الكريم، البريد الإلكتروني، رقم الجوال (+966)، كلمة المرور.
- "انطلق بالبيع مجاناً بلا حدود" — خطة مجانية للبداية.
- "دعم يساعدك تحقق أول طلباتك".
- "طلبات بدون أي عمولة من محلي" (منصة محلي).
- تسجيل عبر Google متاح.

### 2.3 قطاعات (Sectors)
عبايات وأزياء، المنتجات الرقمية، **الصحة واللياقة**، الإلكترونيات، المجوهرات، العناية والتجميل، المطاعم والمقاهي، مستلزمات المنزل، تصميم الخدمات.
> لا يوجد قطاع "صيدلية" مخصص — صيدلية/أدوية OTC تدخل تحت "الصحة واللياقة" أو "العناية والتجميل".

### 2.4 الحلول (Solutions)
- **إنشاء وتدشين المتجر:** خطوات سهلة، 1000+ خدمة من مزوّدي خدمات التاجر، مجتمع تجار.
- **تصميم المتجر:** ثيمات جاهزة قابلة للتخصيص، تخصيص بـ JS/CSS، Salla Twilight (ثيم خاص).
- **المدفوعات:** Mada، Visa، الدفع عند الاستلام، Tabby، Tamara، Spree (اشتر الآن ادفع لاحقاً)، PCI Level 1، تحصيل خلال 24 ساعة.
- **الشحن والتوصيل:** 307+ شركة شحن (محلية/دولية)، 6 شركات مخفضة/حصرية ببوليصات سلة، شحن دولي.
- **أدوات التسويق:** كوبونات، عروض، سلات متروكة، مسوقون بالعمولة، Pixel/Conversion API، مدونة SEO.
- **التوسع:** 40+ لغة، 79+ دولة، فروع/مستودعات متعددة، ERP.
- **متجر التطبيقات:** 832+ تطبيق.
- **صانع التطبيقات:** تطبيق iOS/Android خاص.
- **سلة سبيشل:** ERP، فروع/مستودعات، رسوم دفع مرنة (للكبار).

### 2.5 متاجر سلة (URL pattern)
- `https://salla.sa/<slug>` — أمثلة مكتشفة: `asnas`، `shumul` (شمول)، `atara` (أتارا)، `alahli` (الالعاب غفورجي)، `alqadi` (القاضي)، `antoni` (ANTONI).
- بعض المتاجر "مغلقة حالياً (قيد الصيانة)".
- `salla.sa/<slug>` stores تستخدم ثيم Salla (logo، heading، ...).

### 2.6 مركز المساعدة
- `help.salla.sa` — مكتبة محتوى، مجتمع، مدونة، أكاديمية، أدوات التجار، متجر التطبيقات، صانع التطبيقات، سلة سبيشل، المدفوعات، أدوات التسويق، محلي، شركاء.

### 2.7 أخبار سلة (من الصفحة الرئيسية)
- دخول "أنتونيو سوتوس" (زعفران إسباني) للسوق السعودي عبر سلة.
- سلة تحصل على عضوية "تقنية سعودية" (صنع في السعودية).
- انضمام "القاضي للرحلات" (1967، 11+ فرع) لسلة.
- شراكة "النادي الأهلي" (متجر إلكتروني رسمي).
- "ديوان الذهب" (سبائك/مشغولات) على سلة.

## 3. هل يمكن إضافة "موقع سلة" إلى الصيدلية؟

**نعم.** يمكن إنشاء متجر إلكتروني على منصة سلة **بجانب** (أو كبديل) لموقع النهدي. سلة منصة SaaS مستقلة; التكامل (إن رغبت) عبر روابط/API/iframe.

> ملاحظة: صيدلية النهدي **ليست** على سلة (Next.js مستقل). إضافة "موقع سلة" = إنشاء متجر سلة جديد، وليس "دمج" في النهدي.

### 3.1 متطلبات قانونية/تجارية (KSA)
1. **سجل تجاري (CR)** يشمل نشاط تجارة التجزئة (صيدلية/مستحضرات/مكملات).
2. **تسجيل VAT (ZATCA)** — فواتير ضريبية.
3. **حساب بنكي (IBAN)** باسم المنشأة — تحصيل خلال 24 ساعة.
4. **ترخيص صيدلية (MOH)** + pharmacist مفوّض (للأدوية OTC).
5. **تسجيل المنتجات (SFDA)** — مكملات/أجهزة طبية.
6. **سياسات:** شروط، خصوصية، إرجاع/استبدال، شحن (النهدي يعرض هذه).

### 3.2 متطلبات تشغيلية (منتجات)
1. **كتالوج:** اسم، وصف، صور متعددة، سعر، SKU، باركود، فئات، علامات.
2. **تصنيف:** OTC، مكملات (فيتامينات)، عناية بشرة، تجميل، أجهزة طبية، حفاضات، تغذية.
3. **قيود:** **لا** بيع أدوية بوصفة (Rx) أو مواد خاضعة للرقابة عبر الإنترنت (SFDA/MOH). فقط OTC + مكملات + مستحضرات + أجهزة.
4. **المخزون:** كميات، تنبيهات نفاد، مستودعات/فروع (سلة سبيشل للكبار).
5. **الأسعار:** شاملة VAT، خصومات، عروض.

### 3.3 متطلبات تقنية/تجربة
1. **حساب سلة** (s.salla.sa/auth/register): اسم، بريد، جوال +966، كلمة مرور.
2. **اسم المتجر (slug)** → `salla.sa/<slug>`； إمكانية ربط **نطاق مخصص**.
3. **ثيم/تصميم** (ثيمات جاهزة + CSS/JS، أو Salla Twilight).
4. **بوابات الدفع:** Mada، Visa/MC، Apple Pay، STC Pay، Tabby/Tamara، COD.
5. **الشحن:** 307+ شركة (Aramex, SMSA, Naqel, Zajil, ...) أو 6 شركات مخفضة من سلة.
6. **تطبيق موبايل (اختياري):** صانع التطبيقات.
7. **التسويق:** Pixel/CAPI، كوبونات، سلات متروكة، مدونة SEO، تسويق بالعمولة.
8. **التكاملات:** ERP، WhatsApp، بريد، تحليلات.

### 3.4 متطلبات تشغيلية (فريق)
1. **فريق:** مدير متجر، مدخل بيانات (منتجات)، خدمة عملاء، fulfillment/packing، محاسب.
2. **SLA:** معالجة طلب خلال X ساعة، شحن خلال Y يوم، إرجاع خلال Z يوم.
3. **خدمة عملاء:** WhatsApp/هاتف/بريد، FAQ، تتبع شحنات.

### 3.5 ملاحظات (من التحليل)
- **القطاع (Sector):** اختر "الصحة واللياقة" أو "العناية والتجميل" (لا يوجد قطاع "صيدلية").
- **التكلفة:** البداية مجانية ("انطلق بالبيع مجاناً بلا حدود")； المدفوعات/الشحن/التطبيقات قد تكون بتكلفة (رسوم على المعاملات + باقات سلة سبيشل).
- **الامتثال:** بيع الأدوية online في KSA مقيد (SFDA). ابدأ بـ OTC + مكملات + مستحضرات + أجهزة طبية.

### 3.6 خطوات الإطلاق (Launch Plan)
1. سجل تجاري + VAT + حساب بنكي + ترخيص صيدلية + SFDA.
2. أنشئ حساب سلة (`s.salla.sa/auth/register`) → اختر slug.
3. اختر ثيم → أضف منتجات (صور/أسعار/SKU).
4. فعّل بوابات الدفع + شركات الشحن + مناطق.
5. أضف صفحات (شروط، خصوصية، إرجاع، شحن) + سياسات.
6. اربط نطاق مخصص (اختياري) + تطبيق موبايل (اختياري).
7. اختبر (طلب تجريبي) → أطلق → راقب (تحليلات، سلات متروكة).
8. سوق (محلي، Pixel، كوبونات، التسويق بالعمولة).

## 5. خلاصة (What I Understood)

- **صيدلية النهدي**: متجر Next.js مخصص (وليس Salla) with rich catalog, Express shipping, Mada/Visa/Apple Pay, AR/EN, SA/AE.
- **سلة**: منصة SaaS Saudi e-commerce (مجانية للبداية) with payments, shipping, marketing, apps, Twilight theming; sector "الصحة واللياقة" for pharmacy-like products.
- **إضافة موقع سلة للصيدلية**: ممكن — إنشاء متجر سلة جديد (أو فرعي) مع متطلبات: CR, VAT, IBAN, ترخيص صيدلية, SFDA, كتالوج, بوابات دفع, شحن, سياسات, فريق.
- **قيود**: لا بيع Rx/مواد خاضعة للرقابة online; التزم بـ OTC + مكملات + مستحضرات + أجهزة.
- **التكامل**: النهدي (Next.js) وسلة (SaaS) منصتان مستقلتان — التكامل عبر روابط/API if needed.
